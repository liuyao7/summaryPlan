## 知识库使用指南

### 内容组织原则

1. **理论与实践分离** - 理论知识放在"知识体系"，实践问题放在"实践库"
2. **按领域分类** - 每个技术领域有独立的子目录
3. **按时间组织** - 日记和观察记录按时间归档
4. **保持可扩展** - 目录结构设计支持未来内容扩展

### 文件命名规范

- 使用清晰的中文或英文命名
- 避免使用特殊字符
- Markdown 文件统一使用 `.md` 扩展名
- 代码示例使用 `.js`、`.html` 等对应扩展名

### Obsidian 使用技巧

- 使用 `[[双链]]` 在笔记之间建立关联
- 使用 `#标签` 对知识点进行分类
- 利用图谱视图查看知识关联
- 使用搜索功能快速查找内容
