抽象类abstract
实例：
public abstract class Animal {
    public void eat() {
        System.out.println("eating...");
    }

    public abstract void sleep();
}

abstract不能与哪些关键字共用
答案：final、private、protected、static


接口interface
答案：abstract、final、private、protected、static、public、strictfp、transient
- 类可以实现多个接口
- 类针对于接口的多实现，一定程度上就弥补了类的单继承的局限性
- 类必须将实现接口中的所有抽象方法都重写（或实现），方可实例化。否则，此实现类必须声明为抽象类。

接口与接口的关系：继承关系，且可以多继承

接口的多态性：接口名 变量名 = new 实现类名();

区分抽象类和接口
- 共性：都可声明抽象方法
        都不能实例化
- 不通：抽象类一定有构造器。接口没有构造器
        类与类之间继承关系，类与接口之间是实现关系，接口与接口关系是多继承关系

// jdk8之后，接口中可声明默认方法和静态方法
接口中声明的静态方法只能被接口访问，不能通过实现类访问
接口中声明的默认方法可以被实现类访问并重写


成员内部类
- 和局部内部类一样，具有访问外部类的所有成员的权限
- 通常，当需要在外部类的内部创建类的实例时，将此类声明为成员内部类


枚举类
- 提供了更好的可读性
- 可以添加任意属性、方法、构造器
- 可以实现接口、被其他类继承
- 常用枚举类：Weekday、Color、Direction
定义方式：
public enum Color {
    RED, GREEN, BLU, YELLOW;
}


注解
应用场景：提供程序设计的元数据信息，可被注解解析器解析
- 用于提取文档，如：作者、日期、版本号
- 用于生成各种文档，如：HTML、PDF
- 用于运行时处理，如：验证框架、日志框架、测试框架
定义方式：
1. 注解声明为@interface
2. 成员以抽象方法的形式声明
3. 可以为成员提供默认值
注解的应用场景
- 元数据：使用注解添加元数据
- 编译时检查：使用注解进行编译时检查
- 运行时处理：使用注解在运行时处理
- 依赖注入：使用注解进行依赖注入
