方法区：类模版
栈：方法内的变量
堆：对象，包括对象内定义的属性


方法声明的格式
权限修饰符 [其他修饰符] 返回值类型 方法名（形参列表）[throws 异常类型] { // 方法头
    <!-- 方法体 -->
}
// 注：[]中的内容不是必须的
// 修饰符：public、protected、private、static、final、abstract、synchronized
// 返回值类型：可以是任意类型，包括void
// 方法名：标识方法的名称
// 形参列表：0个或多个，包括类型、名称、可变参数
// throws 异常类型：声明方法可能抛出的异常

// private: 私有，只能在当前类内访问
// protected: 受保护，只能在当前类、当前包、子类中访问
// public: 公共，可以 anywhere 访问
// 默认：不写任何修饰符，只能在当前包内访问
