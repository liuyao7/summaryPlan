# 普通人社会生存常识与底层逻辑

在社会中生存，掌握一些底层的逻辑和常识能够极大地减少内耗，避开很多不必要的坑。以下为几个维度的核心生存法则：

## 一、 人际交往与沟通
1. **不要交浅言深**：刚认识的人，无论感觉多么投缘，都不要轻易暴露自己的底牌、软肋或核心秘密。信任是需要时间测试的。
2. **没有明确答应，就是拒绝**：成年人的世界里，没有爽快的答应（如“我看看”、“到时候再说”），大概率就是体面的拒绝，不要反复追问。
3. **价值交换**：不要过度高估人情的作用。只有当你自身有价值时，别人才会愿意靠近你。提升自己比到处攀附人脉有用得多。
4. **课题分离**：别人的情绪和选择是别人的课题；你的情绪和利益是你的课题。不要为别人的错误买单。

## 二、 职场与工作
1. **工作是交易**：不要把公司当家，不要对老板产生过度情感羁绊。
2. **凡事留痕，学会“免责”**：职场口说无凭，重要的沟通和决策一定要有文字记录（邮件、聊天截图等）。这是保护自己不背锅的最佳武器。
3. **向上管理与及时反馈**：领导最怕“失控感”。件件有着落，事事有回音。
4. **不可替代性**：盲目勤奋容易被替换，找到核心竞争力才能拥有议价权。

## 三、 财富与金钱观
1. **Fuck You Money（应急存款）**：手里有粮，心中不慌。拥有支撑半年生活费的存款，是敢于对烂工作说“不”的底气。
2. **闷声发大财**：不要在朋友圈或亲戚面前炫耀收入和资产，人性最大的弱点是见不得身边的人比自己好。
3. **警惕免费的陷阱**：“免费的往往是最贵的”，背后都标好了极高的隐藏价格。
4. **救急不救穷**：不要轻易借钱给别人，更不要替人做担保。

## 四、 自我保护与底线
1. **别人怎么对你，都是你教的**：第一次被越界时，必须温和而坚定地亮出底线，否则得寸进尺是必然。
2. **保护隐私**：不要在社交平台上过度暴露真实住址和财务状况。
3. **不试图改变他人**：成年人只能筛选，不能教育。强行改变别人只会带来反噬。

## 五、 心态管理
1. **承认世界不公平**：接受现实，在自己拿到的牌里尽力打出最优解，不把精力浪费在抱怨上。
2. **允许一切发生**：降低期待值，遇到好事是惊喜，遇到坏事坦然面对。
