## 1. 产品概述

### 1.1 项目背景

灵感宇宙是一个基于AI大模型和3D渲染技术的个性化灵感探索平台。用户通过输入自己的出生年月日，AI将解析生成与用户相关的关键词、场景意象、主题色和情感基调，然后在一个沉浸式的3D环境中进行探索。

该项目的核心创新点在于：
- **个性化深度**：基于生日的AI解析，为每个用户生成独特的内容
- **3D沉浸体验**：两种探索模式（空间模式 + 场景模式）
- **可扩展性**：场景支持上传和AI解析生成

### 1.2 产品定位

一个将**AI个性化**与**3D沉浸体验**结合的创新型灵感探索平台，面向追求独特体验、寻找灵感和创意的用户。

### 1.3 目标用户

- 追求个性化数字体验的用户
- 对3D交互和沉浸式内容感兴趣的用户
- 寻找创意灵感、想要探索新奇体验的用户

## 2. 核心功能

### 2.1 用户入口

| 功能 | 描述 |
|------|------|
| 生日输入 | 用户提供出生年月日（格式：YYYY-MM-DD） |
| 输入验证 | 验证日期格式和合理性 |
| 进入探索 | 输入完成后触发AI解析，进入探索阶段 |

### 2.2 AI生成模块

| 输出内容 | 描述 |
|----------|------|
| **关键词** | 与用户相关的3-5个核心关键词（如：星辰、海洋、勇气、希望） |
| **场景意象** | 2-3个与用户相关的场景描述 |
| **主题色** | 基于用户特征生成的2-3个颜色（HEX格式） |
| **情感基调** | 用户的情感倾向描述（如：宁静、热情、神秘） |
| **宇宙元素** | 用于空间模式的元素描述（如：星座、行星、星云） |

### 2.3 空间模式

| 功能 | 描述 |
|------|------|
| **3D宇宙空间** | 以用户为中心的粒子宇宙 |
| **粒子系统** | 基于AI生成的主题色渲染粒子 |
| **星体交互** | 可交互的星体节点，点击后展示灵感内容 |
| **点击跳转** | 点击星体可跳转到对应的灵感详情或场景模式 |
| **漫游控制** | 支持鼠标拖拽旋转视角、滚轮缩放 |
| **氛围效果** | 星云、光晕等视觉增强效果 |

### 2.4 场景模式

| 功能 | 描述 |
|------|------|
| **预设场景** | 森林、海边等预设3D环境 |
| **场景选择** | 用户可选择不同场景进行探索 |
| **第一视角漫游** | WASD或方向键控制移动，鼠标控制视角 |
| **场景交互** | 点击场景中的物体展示灵感内容 |
| **环境效果** | 昼夜交替、天气变化等环境效果 |

### 2.5 模式切换

| 功能 | 描述 |
|------|------|
| 模式切换入口 | 在探索过程中可切换空间模式/场景模式 |
| 切换过渡 | 平滑的切换动画过渡 |
| 状态保持 | 切换后保持用户的探索进度和状态 |

## 3. 用户流程

### 3.1 主要流程

```
┌─────────────┐
│   进入网站   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 输入生日日期 │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  AI生成解析  │
│ (关键词/场景  │
│  主题色等)   │
└──────┬──────┘
       │
       ▼
┌─────────────┐   ┌─────────────┐
│  空间模式   │◄──┤  场景模式   │
│  (宇宙探索) │   │  (场景漫游) │
└──────┬──────┘   └──────┬──────┘
       │                  │
       ▼                  ▼
┌─────────────┐   ┌─────────────┐
│ 点击星体/  │   │ 场景交互/  │
│ 灵感节点   │   │ 漫游探索   │
└─────────────┘   └─────────────┘
```

### 3.2 空间模式交互流程

```
进入空间模式
    ↓
粒子宇宙加载
    ↓
用户操作（拖拽/缩放）
    ↓
点击星体节点
    ↓
展示灵感内容（关键词/描述）
    ↓
可切换到场景模式
```

### 3.3 场景模式交互流程

```
选择场景（森林/海边）
    ↓
场景加载
    ↓
第一视角漫游（WASD + 鼠标）
    ↓
点击场景中的交互点
    ↓
展示灵感内容
    ↓
可切换到空间模式
```

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 |
|------|------|
| 3D渲染帧率 | 桌面端 ≥ 60fps，移动端 ≥ 30fps |
| AI响应时间 | ≤ 3秒（生成解析结果） |
| 场景加载时间 | ≤ 5秒（首次加载） |
| 页面首屏加载 | ≤ 2秒 |

### 4.2 兼容性

| 平台 | 要求 |
|------|------|
| 浏览器 | Chrome 90+、Edge 90+、Safari 14+、Firefox 88+ |
| 移动端 | iOS 14+、Android 10+ |
| WebGL | WebGL 2.0 支持 |

### 4.3 用户体验

- 无显著延迟的交互反馈
- 平滑的动画过渡
- 清晰的操作指引
- 响应式设计，适配不同屏幕尺寸

## 5. MVP与迭代规划

### 5.1 MVP 阶段

**目标**：验证核心概念

| 功能模块 | 描述 |
|----------|------|
| 生日输入 | 简单的日期选择器 |
| AI解析 | 调用厂内接口生成基础内容 |
| 空间模式 | 简单的粒子宇宙，可拖拽旋转 |
| 场景模式 | 1-2个预设场景（森林、海边），基础漫游 |
| 模式切换 | 基础的模式切换按钮 |

### 5.2 v2 阶段

**目标**：完善交互体验

| 功能模块 | 描述 |
|----------|------|
| 完整空间模式 | 星体交互、点击跳转、氛围效果 |
| 完整场景模式 | 更多预设场景、环境效果 |
| 灵感详情页 | 丰富的灵感内容展示 |
| 个性化主题 | 根据AI结果应用主题色 |

### 5.3 v3 阶段

**目标**：扩展场景能力

| 功能模块 | 描述 |
|----------|------|
| 场景上传 | 用户可上传图片/描述 |
| AI场景生成 | 基于上传内容生成3D场景 |
| 场景编辑 | 简单的场景编辑功能 |

### 5.4 v4 阶段

**目标**：社区与分享

| 功能模块 | 描述 |
|----------|------|
| 用户系统 | 登录/注册 |
| 灵感收藏 | 收藏喜欢的灵感内容 |
| 分享功能 | 分享到社交平台 |
| 社区探索 | 查看其他用户的灵感宇宙 |

## 6. 数据与统计

### 6.1 核心数据指标

| 指标 | 说明 |
|------|------|
| 用户进入率 | 访问网站到输入生日的比例 |
| AI生成成功率 | AI解析成功返回的比例 |
| 平均停留时长 | 用户在3D场景中的平均停留时间 |
| 模式切换次数 | 空间模式 ↔ 场景模式的切换次数 |
| 灵感交互次数 | 点击星体或场景交互点的次数 |

### 6.2 数据分析计划

- MVP阶段：埋点基础事件（页面浏览、AI调用）
- v2阶段：加入交互事件统计
- v3及以后：用户行为分析、场景偏好分析

## 7. 风险与假设

### 7.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 3D性能不足 | 用户体验差 | 粒子数量优化、LOD策略 |
| AI生成质量不稳定 | 灵感效果不理想 | 提供降级内容、优化提示词 |

### 7.2 假设

- 厂内AI接口支持生日解析和场景生成
- 用户设备支持WebGL 2.0
- 网络环境能够支持3D内容加载
