## 1. 技术架构

### 1.1 技术栈

| 类型 | 技术选型 | 说明 |
|------|----------|------|
| **前端框架** | Next.js 14+ | React服务端渲染框架 |
| **语言** | TypeScript | 类型安全 |
| **3D引擎** | Three.js + React Three Fiber | React式3D渲染 |
| **3D工具** | @react-three/drei | r3f工具库（OrbitControls等） |
| **样式方案** | Tailwind CSS | 原子化CSS |
| **部署平台** | Vercel | Next.js最佳部署方案 |


## 2. 功能模块设计

### 2.1 星空背景 (StarField)

```typescript
interface StarFieldProps {
  starCount?: number;
}

// 功能：
// - 渲染数千颗静态星星
// - 随机分布、随机亮度
// - 基于真实星图的颜色分布
```

### 2.2 星云 (Nebula)

```typescript
interface NebulaProps {
  colors?: string[];
  particleCount?: number;
}

// 功能：
// - 使用 Points 粒子系统
// - 颜色渐变（紫、蓝、粉）
// - 缓慢流动动画
```

### 2.3 可交互星体 (CelestialBody)

```typescript
interface CelestialBodyProps {
  position: [number, number, number];
  size: number;
  color: string;
  name: string;
  type: 'star' | 'planet';
  data: StarData;
  onClick: (data: StarData) => void;
  onHover: (hovered: boolean) => void;
}

interface StarData {
  name: string;
  type: string;
  distance: string;
  description: string;
}
```

### 2.4 信息面板 (InfoPanel)

```typescript
interface InfoPanelProps {
  visible: boolean;
  data: StarData | null;
  onClose: () => void;
}

// 功能：
// - 滑入式面板
// - 展示星体信息
// - 带关闭按钮
```

## 6. 关键技术点

### 6.1 粒子系统优化

- 使用 `THREE.Points` 而非单独Mesh
- 合并几何体，减少draw call
- 使用LOD（Level of Detail）策略

### 6.2 交互实现

- `@react-three/drei` 的 `useThree` hook 获取 raycaster
- `pointerdown` + `pointerup` 区分拖拽和点击
- 悬停状态管理避免频繁更新

### 6.3 性能监控

- `@react-three/drei` 的 `Stats` 组件监控FPS
- 根据设备性能动态调整粒子数量
