## 1. 技术架构

### 1.1 技术栈

| 类型 | 技术选型 | 说明 |
|------|----------|------|
| **前端框架** | Next.js 14+ | React服务端渲染框架 |
| **语言** | TypeScript | 类型安全 |
| **UI组件** | shadcn/ui | 基于Radix UI的高质量组件 |
| **3D引擎** | Three.js + React Three Fiber | React式3D渲染 |
| **状态管理** | Zustand | 轻量级状态管理 |
| **样式方案** | Tailwind CSS | 原子化CSS |
| **AI接口** | 厂内大模型接口 | AI内容生成 |
| **部署平台** | Vercel | Next.js最佳部署方案 |

### 1.2 系统架构

```
┌─────────────────────────────────────────────────────┐
│                   用户浏览器                          │
├─────────────────────────────────────────────────────┤
│  Next.js 应用                                      │
│  ┌──────────┬──────────┬──────────────────────┐  │
│  │  页面层  │  组件层  │    3D 渲染层          │  │
│  └──────────┴──────────┴──────────────────────┘  │
│                    │                               │
│              Zustand 状态管理                      │
├─────────────────────┼─────────────────────────────┤
│                     │                               │
│            API Routes (可选)                       │
│                     │                               │
└─────────────────────┼─────────────────────────────┘
                      │
                      ▼
              ┌───────────────┐
              │  厂内AI接口    │
              └───────────────┘
```

### 1.3 3D渲染架构

```
React Three Fiber (r3f)
    │
    ├── 空间模式
    │   ├── ParticleSystem (粒子系统)
    │   ├── StarField (星空背景)
    │   ├── InteractiveStars (可交互星体)
    │   └── AtmosphereEffect (大气效果)
    │
    └── 场景模式
        ├── SceneContainer (场景容器)
        ├── FirstPersonControls (第一视角控制)
        ├── SceneObjects (场景物体)
        └── InteractionPoints (交互点)
```

### 1.4 AI调用架构

```
用户输入生日
    │
    ▼
前端状态更新
    │
    ▼
触发AI请求 (API Route / 直接调用)
    │
    ▼
厂内AI接口
    │
    ▼
返回解析结果 (关键词/场景/主题色等)
    │
    ▼
更新状态 → 触发3D场景更新
```

## 3. API设计

### 3.1 AI生成接口

**端点**：`/api/parse-birthday`

**方法**：POST

**请求**：
```json
{
  "birthday": "1995-03-15"
}
```

**响应**：
```json
{
  "success": true,
  "data": {
    "keywords": ["星辰", "勇气", "探索", "希望"],
    "scenes": ["静谧的森林小径", "广阔的星空海洋"],
    "themeColors": ["#6366f1", "#8b5cf6"],
    "emotion": "宁静中带着探索的渴望",
    "cosmicElements": ["银河", "彗星", "星云"]
  }
}
```

**错误响应**：
```json
{
  "success": false,
  "error": "AI服务暂时不可用"
}
```

### 3.2 场景数据接口（v3预留）

**端点**：`/api/scenes`

**方法**：GET

**响应**：
```json
{
  "scenes": [
    {
      "id": "forest",
      "name": "森林",
      "thumbnail": "/images/scenes/forest.jpg"
    },
    {
      "id": "beach",
      "name": "海边",
      "thumbnail": "/images/scenes/beach.jpg"
    }
  ]
}
```

## 4. 数据模型

### 4.1 应用状态 (Zustand)

```typescript
// store/appStore.ts
interface AppState {
  // 用户输入
  birthday: Date | null;

  // AI生成结果
  aiResult: {
    keywords: string[];
    scenes: string[];
    themeColors: string[];
    emotion: string;
    cosmicElements: string[];
  } | null;

  // 当前模式
  currentMode: 'space' | 'scene';
  selectedScene: 'forest' | 'beach';

  // UI状态
  loading: boolean;
  error: string | null;

  // Actions
  setBirthday: (date: Date) => void;
  setAiResult: (result: any) => void;
  setMode: (mode: 'space' | 'scene') => void;
  setSelectedScene: (scene: 'forest' | 'beach') => void;
  setLoading: (loading: boolean) => void;
  setError: (error: string | null) => void;
}
```

## 5. 开发计划

### 5.1 阶段划分

| 阶段 | 功能模块 | 预计时间 |
|------|----------|----------|
| **MVP** | 生日输入 + AI解析 + 简单3D宇宙 + 1-2个预设场景 | 1-2周 |
| **v2** | 完整空间模式交互 + 完整场景模式 + 模式切换 | 2-3周 |
| **v3** | 场景上传 + AI场景生成 | 3-4周 |
| **v4** | 用户系统 + 社区分享 | 待定 |

### 5.2 MVP任务分解

#### Week 1

| 任务 | 内容 |
|------|------|
| 项目初始化 | Next.js + TypeScript + Tailwind + shadcn/ui |
| 状态管理 | Zustand store 搭建 |
| 生日输入组件 | 日期选择器 + 验证 |
| AI接口对接 | API Route + 厂内接口调用 |
| AI结果展示 | 关键词、主题色展示组件 |

#### Week 2

| 任务 | 内容 |
|------|------|
| 空间模式基础 | 简单粒子系统 + 星空背景 |
| 场景模式基础 | 森林场景 + 第一视角漫游 |
| 模式切换 | 基础切换按钮 |
| 测试与优化 | 跨浏览器测试 + 性能优化 |

### 5.3 v2任务分解

| 任务 | 内容 |
|------|------|
| 空间模式增强 | 可交互星体 + 点击跳转 + 氛围效果 |
| 场景模式增强 | 海边场景 + 环境效果 |
| 灵感详情页 | 灵感内容详情展示 |
| 主题应用 | 基于AI结果应用主题色 |

### 5.4 v3任务分解

| 任务 | 内容 |
|------|------|
| 上传功能 | 图片/描述上传 |
| AI场景生成 | 基于上传内容生成3D场景描述 |

## 7. 风险与挑战

### 7.1 技术风险

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 3D性能不足 | 中 | 高 | 粒子数量优化、LOD策略、降级方案 |
| AI接口不稳定 | 中 | 中 | 重试机制、缓存策略、降级内容 |
| 移动端兼容性 | 低 | 中 | 渐进式3D效果、降级方案 |
| 厂内接口限制 | 低 | 高 | 提前沟通接口规格，准备备选方案 |

### 7.2 开发风险

| 风险 | 缓解措施 |
|------|----------|
| 时间估算偏差 | MVP优先，后续迭代 |
| 需求变更 | 保持架构灵活性 |
| 3D技术学习曲线 | 使用React Three Fiber降低复杂度 |

### 7.3 产品风险

| 风险 | 缓解措施 |
|------|----------|
| 用户留存率低 | 加强交互反馈，优化引导流程 |
| AI生成质量 | 优化提示词，提供用户反馈机制 |
