1. 安装brew。可以网上搜下mac电脑如何安装。  
    
2. brew install scrcpy  
    
3. brew install android-platform-tools  
    
4. scrcpy 电脑连接上手机，执行这个命令就可以将手机投屏到电脑上。  
    

  

**手机端操作：**

1. **设置 → 开发者选项 → 无线调试** → 打开
2. 点击 **“使用配对码配对设备”**
3. 手机会显示：

- IP 地址和端口（如 192.168.1.5:37001）
- 配对码（如 123456）

**电脑端操作：**

_#_ 第一步：配对

adb pair 192.168.1.5:37001

_#_ 输入手机显示的配对码，回车

  

_#_ 第二步：连接（用无线调试页面显示的另一个端口）

adb connect 192.168.1.5:5555

  

_#_ 第三步：投屏

scrcpy

  

关闭的话直接关闭窗口

  

完全断开链接

adb disconnect
