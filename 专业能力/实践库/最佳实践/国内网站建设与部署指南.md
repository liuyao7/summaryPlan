## 一、法律合规与准备工作（中国特色）

### 1. ICP 备案（必须）

**作用**：国内服务器上线网站必须完成工信部备案

**流程**：
1. 购买国内云服务器（阿里云、腾讯云、华为云等）时同步提交备案
2. 提交主体信息：
   - 个人：身份证正反面、人脸核验
   - 企业：营业执照、法人人脸核验
3. 提交网站信息：域名、网站名称、服务内容
4. 云厂商初审 -> 省通信管理局审核
5. 备案号下发，网站可正式上线

**时效**：
- 个人：通常 7-20 个工作日
- 企业：15-30 个工作日

**注意**：
- 未备案的网站使用国内服务器会被直接拦截封禁
- 备案号需在网站底部显眼位置展示
- 备案期间网站无法访问

### 2. 域名准备

**选择域名注册商**：
- 国内：阿里云、腾讯云、GoDaddy（国内站）
- 国外：Namecheap、GoDaddy（国外站）

**建议**：
- 首选 `.com`，其次 `.cn`
- 简短易记，避免生僻字
- 避免侵权风险

**实名认证**（国内注册商强制要求）：
- 提交身份证信息
- 完成实名认证后方可使用

### 3. 内容合规（重要）

**禁止内容**：
- 违反国家法律法规的内容
- 涉政、暴力、色情、赌博
- 侵犯他人版权、隐私
- 诈骗、传销

**行业资质要求**：
- 个人博客/展示类：一般问题不大
- 涉及新闻、出版、教育、医疗、金融等特殊行业：需要前置审批许可
  - 《互联网新闻信息服务许可证》
  - 《网络文化经营许可证》
  - 《互联网药品信息服务资格证书》等

**合规建议**：
- 添加《用户协议》《隐私政策》页面
- 设置用户评论审核机制
- 定期自查网站内容

## 二、技术选型与开发

### 1. 确定网站类型

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 静态网站 | 无后端，纯 HTML/CSS/JS | 个人博客、产品介绍页、文档站 |
| 动态网站 | 有后端，数据库交互 | 电商、论坛、用户管理系统 |
| 小程序 H5 | 在微信生态内传播 | 营销活动、社交裂变 |

### 2. 技术栈选择

**静态网站（推荐新手）**：

| 框架 | 语言 | 优势 |
|------|------|------|
| Hugo | Go | 极速构建，配置简单 |
| Hexo | Node.js | 插件丰富，中文文档完善 |
| VuePress | Vue | 适合技术文档 |
| Astro | JavaScript | 极致性能优化 |

**优势**：
- 安全：无后端漏洞
- 低成本：CDN 托管即可
- 易维护：无需服务器运维

**动态网站**：

| 分类 | 技术选型 |
|------|----------|
| 前端 | Vue、React、Next.js、Nuxt.js |
| 后端 | Node.js (Express/Nest)、Python (Django/FastAPI)、Go、Java (Spring Boot) |
| 数据库 | MySQL、PostgreSQL、MongoDB、Redis |

**CMS 快速搭建**：

| CMS | 特点 |
|-----|------|
| WordPress | 插件生态丰富，适合博客、企业站 |
| Typecho | 轻量级博客系统 |
| Strapi | Headless CMS，前后端分离 |
| Directus | 自动生成管理后台 |

### 3. 本地开发

**环境准备**：
- 安装 Node.js（建议 16.x 以上）
- 安装 Git（版本控制）
- 安装代码编辑器（VS Code）

**项目初始化**：
```bash
# 使用 Vite 创建 Vue 项目
npm create vite@latest my-website -- --template vue
cd my-website
npm install
npm run dev
```

**本地测试**：
- 访问 `http://localhost:5173`（Vite 默认端口）
- 使用浏览器开发者工具调试
- 响应式布局测试（手机/平板）

**版本管理**：
```bash
git init
git add .
git commit -m "Initial commit"
# 推送到 GitHub/GitLab
```

## 三、服务器选择与配置

### 1. 云服务器（主流选择）

**国内云厂商对比**：

| 厂商 | 优势 | 适用场景 |
|------|------|----------|
| 阿里云 | 产品线全，生态成熟 | 企业级应用、大流量 |
| 腾讯云 | 微信生态集成好 | 小程序、游戏、直播 |
| 华为云 | 安全性能强 | 政企项目、AI 场景 |
| UCloud | 性价比高 | 个人开发者、初创团队 |

**配置建议**（个人/小型项目）：
- CPU：1-2 核心
- 内存：2GB
- 存储：40GB SSD
- 带宽：1-3 Mbps（按量付费）
- 预算：约 50-150 元/月

**地区选择**：
- 面向全国：北京、上海、广州
- 特定区域：选择最近的数据中心

### 2. 轻量应用服务器/容器

**轻量应用服务器**：
- 阿里云轻量应用服务器
- 腾讯云轻量应用服务器
- 优势：预装环境，开箱即用

**云原生容器**：
- 阿里云容器服务 ACK
- 腾讯云 TKE
- 优势：K8s 编排，适合微服务

### 3. 服务器操作系统

| 系统 | 特点 | 推荐人群 |
|------|------|----------|
| Ubuntu 22.04 LTS | 社区活跃，文档丰富 | 新手首选 |
| Debian 12 | 稳定，资源占用低 | 服务器生产环境 |
| Rocky Linux 8/9 | CentOS 替代品 | 熟悉 CentOS 的用户 |
| CentOS 7 | 即将停止维护（2024-06） | 不推荐新项目 |

### 4. 环境配置

**安装 Nginx（Web 服务器）**：
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install nginx

# 启动 Nginx
sudo systemctl start nginx
sudo systemctl enable nginx

# 检查状态
sudo systemctl status nginx
```

**安装 Node.js**：
```bash
# 使用 NodeSource 仓库（推荐安装 18.x）
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# 验证版本
node -v
npm -v
```

**安装 PM2（进程管理）**：
```bash
sudo npm install pm2 -g
```

**安装数据库**（以 MongoDB 为例）：
```bash
# 添加 MongoDB 仓库
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list

# 安装 MongoDB
sudo apt update
sudo apt install -y mongodb-org

# 启动 MongoDB
sudo systemctl start mongod
sudo systemctl enable mongod
```

## 四、部署流程

### 1. 域名解析

在域名注册商处添加 DNS 记录：

**A 记录**：
```
类型: A
主机记录: @
记录值: 你的服务器公网 IP
TTL: 600
```

**CNAME 记录**（如果需要子域名）：
```
类型: CNAME
主机记录: www
记录值: 你的主域名
TTL: 600
```

**验证解析**：
```bash
# 本地测试
nslookup yourdomain.com
# 或
dig yourdomain.com
```

### 2. 服务器安全配置

**防火墙设置**（使用 UFW）：
```bash
# 启用防火墙
sudo ufw enable

# 允许 SSH
sudo ufw allow 22

# 允许 HTTP 和 HTTPS
sudo ufw allow 80
sudo ufw allow 443

# 查看状态
sudo ufw status
```

**云安全组配置**：
在云厂商控制台配置安全组规则：
- 入站：TCP 22（你的 IP）、TCP 80、TCP 443
- 出站：全部允许

**SSH 安全**：
```bash
# 修改 SSH 配置
sudo nano /etc/ssh/sshd_config

# 关键配置
PermitRootLogin no              # 禁止 root 登录
Port 2222                      # 修改默认端口
PasswordAuthentication no      # 禁用密码登录（使用 SSH 密钥）

# 重启 SSH 服务
sudo systemctl restart sshd
```

**安装 fail2ban（防暴力破解）**：
```bash
sudo apt install fail2ban
sudo systemctl enable fail2ban
sudo systemctl start fail2ban
```

### 3. 部署应用

**方案 A：传统部署方式**

```bash
# 本地打包
npm run build

# 上传到服务器
scp -r dist user@yourserver:/var/www/html

# 服务器解压
cd /var/www/html && unzip dist.zip

# 设置权限
sudo chown -R www-data:www-data /var/www/html
```

**方案 B：使用 PM2 部署 Node.js 应用**

```bash
# 上传代码到服务器
scp -r . user@yourserver:/var/www/myapp

# 进入项目目录
cd /var/www/myapp

# 安装依赖
npm install --production

# 启动应用
pm2 start npm --name "myapp" -- start

# 设置开机自启
pm2 startup
pm2 save
```

**方案 C：CI/CD 自动化部署（推荐）**

创建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy to Server

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Build
        run: |
          npm install
          npm run build

      - name: Deploy to Server
        uses: easingthemes/ssh-deploy@v4.1.5
        with:
          SSH_PRIVATE_KEY: ${{ secrets.SSH_PRIVATE_KEY }}
          REMOTE_HOST: ${{ secrets.REMOTE_HOST }}
          REMOTE_USER: ${{ secrets.REMOTE_USER }}
          TARGET: /var/www/html
          SOURCE: "dist/"
```

### 4. HTTPS 配置（SSL 证书）

**使用 Let's Encrypt 免费证书**：

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书（自动配置 Nginx）
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# 测试自动续期
sudo certbot renew --dry-run
```

**Nginx 配置示例**：

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name yourdomain.com www.yourdomain.com;

    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;

    root /var/www/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 五、运维与监控

### 1. 日志监控

**Nginx 访问日志**：
```bash
# 实时查看访问日志
sudo tail -f /var/log/nginx/access.log

# 查看错误日志
sudo tail -f /var/log/nginx/error.log
```

**应用日志**：
```bash
# PM2 日志
pm2 logs myapp

# MongoDB 日志
sudo tail -f /var/log/mongodb/mongod.log
```

### 2. 性能监控

**云厂商监控**：
- CPU、内存、磁盘、网络流量
- 设置告警阈值（如 CPU > 80%）

**应用性能监控（APM）**：
- 阿里云 ARMS
- 腾讯云云监控
- New Relic、DataDog

### 3. 备份策略

**数据库备份**：
```bash
# MongoDB 备份
mongodump --db mydatabase --out /backup/mongodb

# 设置定时备份（crontab）
0 2 * * * mongodump --db mydatabase --out /backup/mongodb
```

**代码备份**：
- Git 仓库（GitHub/GitLab）
- 定期拉取到备份服务器

### 4. CDN 加速

**静态资源托管**：
- 上传到对象存储（阿里云 OSS、腾讯云 COS）
- 配置 CDN 加速

**CDN 配置**：
1. 添加域名到 CDN
2. 配置回源地址（服务器 IP）
3. 配置缓存规则
4. 配置 HTTPS

**优势**：
- 提升访问速度
- 节省服务器带宽成本
- DDoS 防护

## 六、常见替代方案（快速上线）

### 1. Serverless/云函数

**平台**：
- 阿里云函数计算 FC
- 腾讯云云函数 SCF
- AWS Lambda（需备案）

**优势**：
- 无需运维
- 按量付费
- 自动扩缩容

**适用场景**：
- 轻量级应用
- API 接口
- 定时任务

### 2. 托管平台（海外）

| 平台 | 优势 | 缺点 |
|------|------|------|
| Vercel | 自动化部署、免费额度 | 国内访问不稳定 |
| Netlify | 简单易用、集成度高 | 同上 |
| Cloudflare Pages | 全球 CDN、无限带宽 | 同上 |

**适用场景**：
- 静态网站
- 个人项目
- 不备案

### 3. SaaS 平台

| 平台 | 特点 |
|------|------|
| WordPress.com | 一键建站 |
| Ghost | 专注于博客 |
| Notion | 生成简单网站 |

**适用场景**：
- 零技术门槛
- 快速上线

## 八、快速开始推荐路径

### 路径 A：纯静态网站（博客/展示页）

**适合人群**：新手、个人博客、产品介绍页

**步骤**：
1. 使用 Hexo/Hugo 生成本地静态文件
2. 购买域名 + 备案
3. 阿里云 OSS + CDN 托管
4. 绑定域名，完成

**优势**：
- 成本极低（OSS+CDN 每年约 100 元）
- 无需服务器运维
- 访问速度快

### 路径 B：动态网站（有后端/数据库）

**适合人群**：有后端开发经验、需要用户系统

**步骤**：
1. 本地开发（Vue + Node.js）
2. 购买云服务器（Ubuntu）
3. 安装 Nginx + Node.js + MongoDB
4. 配置 GitHub Actions 自动部署
5. 域名解析 + SSL 证书
6. 完成

**优势**：
- 功能强大，可扩展
- 完全控制

### 路径 C：Serverless 快速上线

**适合人群**：快速原型、轻量级应用

**步骤**：
1. 本地开发（Next.js）
2. 部署到 Vercel
3. 购买域名 + 配置 DNS
4. 完成

**优势**：
- 极速上线
- 免费额度够用

## 常见问题 FAQ

**Q: 必须备案吗？**
A: 使用国内服务器必须备案。使用海外服务器（如 Vercel）可以不备案，但国内访问速度可能不稳定。

**Q: 备案期间网站能访问吗？**
A: 不能。建议先在本地开发，备案完成后再部署。

**Q: 可以先部署再备案吗？**
A: 不可以。使用国内服务器，未备案的网站会被拦截。

**Q: 个人能备案吗？**
A: 可以。个人备案要求必须是个人网站，不能有经营性质。

**Q: 备案需要多长时间？**
A: 个人通常 7-20 个工作日，企业 15-30 个工作日。

**Q: SSL 证书需要花钱吗？**
A: 不需要。Let's Encrypt 提供免费证书，各大云厂商也提供一年期免费证书。

**Q: 服务器选 1 核还是 2 核？**
A: 初期 1 核够用，流量增长后可升级。

**Q: 可以用 GitHub Pages 吗？**
A: 可以，但国内访问可能不稳定，且需要备案才能绑定国内域名。
