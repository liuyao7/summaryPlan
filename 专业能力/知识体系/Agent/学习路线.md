# Agent 工程师学习路线

> 背景：前端工程师转 Agent 方向。前端优势在于"离用户最近"和"交互工程能力"，应充分发挥在构建 AI 应用 UI、流式渲染、状态管理等方面的积累。

## 阶段一：理解 Agent 本质（1-2周）

目标：搞懂 Agent 到底是怎么运转的，能自己手写一个最简版。

- [ ] 理解 ReAct 范式（Reason + Act）：思考 → 行动 → 观察 → 循环
- [ ] 手写一个最简 Agent（~200行 Python 或 JS）
  - 调用一个大模型 API（如 DeepSeek / OpenAI / Claude）
  - 给模型描述一个工具（如 `get_weather(city)`）
  - 实现"模型决定调用工具 → 执行 → 结果喂回去"的循环
- [ ] 对比理解：Workflow（流程固定）和 Agent（LLM 动态决策）的本质区别

**产出**：一个能自行决定"要不要查天气"的最简 Agent

---

## 阶段二：工具调用与 MCP（1-2周）

目标：让 Agent 能真正干活——连上搜索引擎、数据库、外部 API。

- [ ] 深入 Function Calling 机制：如何向模型描述函数、解析模型的调用意图
- [ ] 学习 MCP（Model Context Protocol）协议
  - 理解 Client-Server 架构
  - 搭建一个 MCP Server（如文件系统读写、数据库查询）
  - 让 Agent 通过 MCP 调用外部服务
- [ ] 熟练调用主流模型 API：OpenAI / Anthropic / DeepSeek / 智谱 / 百度文心
- [ ] 掌握 Prompt Engineering 核心技巧
  - 结构化输出（强制 JSON 格式，对前后端对接至关重要）
  - Few-shot prompting
  - System Prompt 设计

**产出**：一个能联网搜索 + 读写文件的 Agent

---

## 阶段三：记忆系统与 RAG（2-3周）

目标：让 Agent 拥有"记忆"，不再每次从零开始。

- [ ] 理解记忆分层架构：工作记忆 / 短期记忆 / 长期记忆 / 程序性记忆
- [ ] 学习向量化（Embedding）原理和常见模型
- [ ] 学习向量数据库：Chroma（入门）→ Qdrant / Milvus / Pinecone
- [ ] 掌握 RAG（检索增强生成）完整流程：
  - 文档分块（Chunking）
  - 向量化存储
  - 相似度检索（Similarity Search）
  - 重排序（Re-ranking）
  - 上下文注入 LLM
- [ ] 了解 GraphRAG（知识图谱 + RAG，前沿方向）
- [ ] 了解轻量替代方案：SQLite + FTS5 全文搜索（Hermes 方案，适合个人项目）

**产出**：一个能基于知识库回答问题的 RAG Agent

---

## 阶段四：Agent 框架与编排（2-4周）

目标：不再手写所有逻辑，用成熟框架搭建复杂 Agent 系统。

- [ ] 学习 LangChain.js（TypeScript 版本，与前端天然契合）
  - Chain、Agent、Tool 的抽象
  - LCEL（LangChain Expression Language）
- [ ] 学习 LangGraph：构建有状态的、多步骤的 Agent 工作流
- [ ] 学习 LlamaIndex：侧重数据连接和 RAG
- [ ] 学习 CrewAI：多 Agent 角色分工协作
- [ ] 了解 Dify / Coze（低代码编排平台，理解其底层逻辑）
- [ ] **选一个做深度实战项目**（不推荐泛泛全学，选一个精进）

**产出**：用框架搭建一个多步骤的复杂 Agent 应用

---

## 阶段五：发挥前端优势——AI 交互（2-3周）

目标：把 Agent 包装成能打的产品，这是前端工程师最大的价值区。

- [ ] 深入 Streaming（流式传输）
  - Server-Sent Events (SSE) 接收流式数据
  - 前端优雅渲染打字机效果
  - 支持用户中途打断（Interrupt / AbortController）
- [ ] Agent 思考过程可视化
  - 展示 Agent 的"内心独白"（Planning、Tool Calling、Observing）
  - 类似于 Manus / Cursor 的交互体验
- [ ] 全栈整合：Next.js / Nuxt 构建 AI 应用
  - API Route 中运行 LangChain.js
  - 复杂状态管理（Agent 执行过程中的 UI 状态同步）
- [ ] 复杂交互组件：富文本编辑器 + AI（Slate.js / ProseMirror / Tiptap）
- [ ] 可选的进阶方向：WebLLM（浏览器端跑模型，WASM + WebGPU）

**产出**：一个具备流式输出 + Agent 过程可视化的完整 AI 应用

---

## 阶段六：研读代表性开源源码（持续）

目标：通过读源码理解顶级 Agent 的工程设计。

- [ ] 读 OpenClaw（43万行 TypeScript）
  - 学习 Gateway 架构、MessageBus 解耦
  - 学习多 Agent 编排和 Cron 定时任务
  - 学习五层容错机制
- [ ] 读 Hermes Agent（Python + SQLite）
  - 学习闭环自学习循环
  - 学习四层记忆系统 + MemPalace
  - 学习多模型编排（Auxiliary Models）
- [ ] 读 MiniClaw（~2700行 Python，OpenClaw 的核心架构浓缩版，更适合入门）

**产出**：对 Agent 引擎的工程实现有深入理解

---

## 阶段七：生产化能力（2-3周）

目标：让 Agent 从 Demo 变成可上线的产品。

- [ ] 可观测性：LangSmith / Langfuse 全链路追踪
- [ ] 评估体系：LLM-as-a-Judge 自动化评测
- [ ] 成本控制：Token 追踪、模型降级策略
- [ ] 安全：沙箱隔离（Docker/E2B）、权限控制、审计日志
- [ ] 部署：Docker / K8s / Serverless
- [ ] 容错：重试机制、模型回退链、优雅降级

**产出**：一个生产级别的 Agent 应用

## 学习原则

1. **以项目驱动，不要以理论驱动**：每学一个东西都要做出一个小东西来。前端的优势就是"能造"，要利用好。
2. **先搞循环，再叠能力**：ReAct 循环是地基，后面的都是在地基上盖楼。
3. **一个框架用到精，不要每个都泛泛**：从 LangChain.js / LangGraph / LlamaIndex 中选一个主攻。
4. **评估思维要早建立**：不要只会调 Prompt，要学会"怎么知道 Agent 到底好不好"。
5. **把你的小项目发出来**：发到 V2EX / 掘金 / GitHub / 即刻，用外部反馈做驱动力。这也呼应了你之前关于"价值感与执行力"的思考——发声，然后听回音。
