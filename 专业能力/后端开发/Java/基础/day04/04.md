方法的重写：重写的方法的权限修饰符不小于被重写的方法的权限修饰符；方法名和形参列表完全一致；返回值类型必须是被重写方法返回值类型或其子类；如果被重写的方法是finalize方法，那么重写的方法也必须是finalize方法

super

多态 适用性：适用于方法，不适用于属性

static
- 静态方法：属于类，不属于对象；可以通过类名直接访问，也可以通过对象访问
- 静态属性：属于类，不属于对象；可以通过类名直接访问，也可以通过对象访问
- 静态代码块：随着类的加载而执行，只执行一次


单例模式
饿汉式：
class ClassName {
    private static final ClassName INSTANCE = new ClassName();

    private ClassName() {}

    public static ClassName getInstance() {
        return INSTANCE;
    }
}

懒汉式
```java
class ClassName {
    private static ClassName INSTANCE;

    private ClassName() {}

    public static ClassName getInstance() {
        if (INSTANCE == null) {
            INSTANCE = new ClassName();
        }
        return INSTANCE;
    }
}
```

两种模式的优缺点：
饿汉式：优点是实现简单，缺点是如果实例化对象后未使用，会造成资源浪费；
懒汉式：优点是节省资源，缺点是实现复杂，存在线程不安全问题。


静态代码块
- 随着类的加载而执行
- 通常用于静态属性的初始化
- 类加载完成之前完成执行，且只执行一次

非静态代码块
- 随着对象的创建而执行
- 每次对象创建时都会执行，可能会执行多次
- 通常用于动态属性的初始化


final
- 用于类：表示类不能被继承
- 用于方法：表示方法不能被重写
- 用于属性：表示属性不能被修改（常量）

final与static搭配表示全局常量
